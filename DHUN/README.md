# DHUN'26 Event Registration & Pass Generator

A clean, standalone **HTML + CSS + JavaScript** website matching **[vsob.in/dhun-26](https://vsob.in/dhun-26)** with:
- **Instant Digital Entry Pass / Card Generation** (with attendee details and live scannable QR code).
- **Dummy / Non-Mandatory Payment**: Shows the ₹200 fee, payment methods, and breakdown, but accepts anything or auto-bypasses payment so you get the card immediately.
- **100% Standalone & Offline Ready**: No `node_modules`, no server, and no build tools required.

---

## 🚀 How to Open and Use

Simply double-click **`index.html`** to open it directly in any web browser (Chrome, Edge, Firefox, Safari).

---

## 🌟 Features Included

1. **Exact vsob.in/dhun-26 Design**:
   - Vishveshwarya School of Business (VSOB) branding, official logos, and helpline numbers.
   - High-definition official campus hero banner with **Abhimanyuu & Solfege Live, Saturday, 17 October 2026**.
   - Floating input labels, responsive layout, and sticky event sidebar with ₹200 pricing and date.

2. **Registration Form**:
   - Full Name, Father's Name, Mobile (+91), Email, College ID.
   - Dynamic Programme and Branch selector.
   - Optional photo upload to display your photo directly on the pass card.

3. **Payment Method (Dummy & Non-Mandatory)**:
   - Visibly displays the ₹200 payment section for authentic visual fidelity.
   - Any payment reference or one-click submit is auto-accepted without requiring real payment.

4. **Official Holographic Event ID Card**:
   - High-contrast VIP pass design with lanyard slot.
   - Unique Registration ID (e.g., `DHUN26-VSOB-849120`).
   - Scannable QR code for entry verification.
   - **Download Pass (PNG)** button to save the card directly to your gallery/downloads.
   - **Print / Save as PDF** button.
   - **Show at Gate (Full Screen)** button for showing to bouncers / security guards.

5. **Find My Registration ID**:
   - Search by mobile and email to retrieve previously generated passes stored in your browser.
